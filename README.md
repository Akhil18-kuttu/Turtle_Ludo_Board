🎲 Ludo Board with Python Turtle
🐢 About

A simple Python Turtle project that draws a colorful Ludo board using basic shapes, loops, and colors. Great for beginners learning Turtle Graphics and coordinate-based drawing in Python.

🚀 Features

Draws a complete Ludo board

Uses loops and color fills

Beginner-friendly and easy to customize

🛠️ Requirements

Python 3.x

Built-in turtle module (no extra installation needed)

▶️ Run the Project 

python ludo_board.py

💡 Learnings

Turtle graphics basics

Drawing with loops and coordinates

Simple design and color handling
